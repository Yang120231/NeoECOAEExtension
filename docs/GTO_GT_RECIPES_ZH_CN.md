# GTO 0.5.6 GT 联动配方

本分支使用 GTOCore 0.5.6-beta / GTCEu 26.7.3。共 23 条 GT 机器配方，沿用普通 1.20.1 GT 路线的材料数量、加工时间和 EU/t。

## 注册与展示

- `GTORecipeRegistrationMixin` 在 `Data.commonInit` 调用 `RecipeBuilder.finish()` 前注册，先于 GTO 汇总配方、建立机器搜索表和 EMI 缓存。客户端与专服均执行。
- `ECOGtoMachineRecipes` 使用实际依赖的原生配方构建器。GT 机器配方不经过原版 `RecipeManager`，不向数据包添加该版本无法解析的 `gtceu:*` 配方 JSON。
- 现有 `gt_gto` 数据包继续负责 ECO 工作站、主机、核心和存储制作路线，保留 GTO 专用等级、数量、耗能及无限组件互换规则。

## 制作链与资源

- 首批盈能水晶保留原有雷击晶芽获取方式；高压釜提供后续增殖路线。基础合金、盈能材料和处理器可以在获得 ECO 集成工作站前使用 GT 机器制作。
- 首台集成工作站改由 EV 组装机制作，使用 EV 机器外壳、电路、电机与焊锡合金。
- 屏蔽 8 条工作台、熔炉及变换合成捷径，与普通版 GT 路线一致；保留材料回收和已有 ECO 工作站加工路线。
- 补充硅板兼容标签：GT 硅板与 AE 印刷硅板。
- 恢复空白集成工作站升级卡的物品、模型、纹理和中英文名称，仅用作制作材料。每个大集成工作站接口增加 2 张空白卡，不恢复其他附属模组模块。

## 验证边界

核对锁定依赖和目标实例 GTOCore JAR、23 条配方定义与条件、Mixin 调用位置、资源及源码归档，并执行 Java 17 Gradle 构建。机器实际加工和 EMI 游戏内展示仍需使用新包启动验证。
