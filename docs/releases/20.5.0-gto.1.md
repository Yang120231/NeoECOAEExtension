## 中文

**Minecraft 1.20.1 / Forge · GregTech Odyssey 专用预发布版**

基于 Neo ECO AE Extension 20.5.0，适配 GregTech Odyssey 0.6.0.23：GTOCore 26.10.9、GTO GTM 26.10.70、GTO AE2 15.2610.31。目标实例使用 Java 21。

### 支持与改进

- 适配 GTO 原生合成 CPU 与样板派发接口，保留 ECO 合成规划、加工记账和工作站任务归属。
- 恢复单体集成工作站、大型集成工作站的配方加载及 EMI 分类，支持配方重载和旧配方清理。
- 支持使用 GTO 样板修改器 Pro 修改 ECO 大型集成工作站通信接口中的样板。
- 适配 GTO AE2 的库存、精确数量同步与嵌套网络存储列举接口。

### 修复

- 修复 AE2 图标默认接口调用不兼容引发的 `IncompatibleClassChangeError`，避免普通 AE2 界面绘制图标时崩溃。
- 补全天空石粉的 `forge:dusts/sky_stone` 标签，使 AE2 天空石粉可用于依赖该标签的凛冰及凛冰晶体配方。

### 安装与验证范围

- 将 `neoecoae-20.5.0-gto.1.jar` 放入目标 GTO 实例的 `mods`，并移除旧的 NeoECOAE JAR。源码包供开发者使用；本次不分发临时终端诊断模组。
- 本版本面向上述 GTO 依赖组合，普通 AE2 整合包请使用普通版本。
- 16 项 GTO 专题回归测试通过。此前已验证目标实例中的配方目录、EMI 界面和工作站加工；本次图标修复仍待完整游戏内交互复验。
- 本次仅发布到 GitHub，以预发布版提供；完整旧测试套件、全部附属组合和独立专服尚未完成验收。

## English

**Minecraft 1.20.1 / Forge · GregTech Odyssey prerelease**

Based on Neo ECO AE Extension 20.5.0, targeting GregTech Odyssey 0.6.0.23 with GTOCore 26.10.9, GTO GTM 26.10.70 and GTO AE2 15.2610.31. The target instance uses Java 21.

### Support and improvements

- Adapt GTO's native crafting CPU and pattern dispatch interfaces while preserving ECO planning, processing accounting and workstation job ownership.
- Restore recipe loading and EMI categories for both integrated workstations, including recipe reloads and removal of stale recipes.
- Support GTO's Pattern Modifier Pro on the ECO Large Integrated Workstation communication interface.
- Adapt GTO AE2 inventory APIs, exact amount synchronization and nested network storage listing.

### Fixes

- Fix the incompatible AE2 icon default-interface call that caused `IncompatibleClassChangeError` when ordinary AE2 screens rendered icons.
- Add AE2 sky stone dust to `forge:dusts/sky_stone`, allowing it to satisfy the tag used by cryotheum and cryotheum crystal recipes.

### Installation and verification

- Install `neoecoae-20.5.0-gto.1.jar` in the target GTO instance's `mods` directory and remove the previous NeoECOAE JAR. The sources archive is for developers; the temporary terminal diagnostic mod is not distributed.
- This build targets the GTO dependency versions listed above. Use the regular edition for ordinary AE2 modpacks.
- All 16 focused GTO regression tests passed. Earlier instance checks covered recipe catalogs, EMI screens and workstation processing; the icon fix still requires complete in-game interaction verification.
- This prerelease is published on GitHub only. The full legacy test suite, all addon combinations and a standalone dedicated server have not completed acceptance testing.
