## 中文

**Minecraft 1.20.1 / Forge · GregTech Odyssey 专用预发布版 · 支持 Dev25**

本版本支持 GregTech Odyssey **0.6.0-dev25（Dev25，实例目录版本号 0.6.0.25）**。
GTO 专版从本次起跟随对应整合包版本号命名，不再使用常规 ECO 的 `20.x-gto.x` 编号。

对比已发布版本：`20.5.1-gto.1`

### 支持与改进

- 适配 Dev25 的 GTO AE2 合成确认入口，保留 ECO 合成规划、确认提交和加工记账。
- 适配 GTO 合成 CPU 状态界面的暂停读取、暂停设置、合成结果同步与待处理位置查询，保留对应原生功能。
- 大型工作站升级模块按对应附属 Mod 的实际加载状态注册。

### 修复

- 修复 Dev25 合成确认入口存在重载时无法匹配提交注入点的问题。
- 修复打开合成状态界面时，将 ECO CPU 包装器直接转换为 GTO 原生 CPU 类型导致的崩溃。
- 修复 CPU 界面桥接的 Mixin 优先级冲突，避免客户端在启动注册阶段崩溃。
- 包含原 `20.5.2-gto.1` 的掉落表修复：水晶簇、水晶芽、盈能水晶母岩、铝矿和钨矿共 9 张掉落表使用符合 Minecraft 1.20.1 的精准采集谓词；盈能水晶簇普通挖掘掉落 4 个盈能水晶，精准采集掉落方块本身。

### 安装与验证范围

- 本次适配并核对的实例组合为 GTO **0.6.0-dev25**、Forge **47.4.20**、GTOCore **26.10.18**、GTO AE2 **15.2610.40**，使用 **Java 21**。
- 客户端和服务端均替换为 `neoecoae-0.6.0-dev25.jar`，移除旧版 NeoECOAE JAR；网络握手要求两端 ECO 版本完全一致。
- 修复后的 27 项 GTO 专项回归测试全部通过、无跳过；实际完整实例启动已通过原崩溃点，运行时合成 CPU 菜单的四处桥接均已确认命中，Dev25 实例已确认修复正常。
- 本次不新增独立专服、全部附属组合或完整旧测试套件的验收结论。
- 本次仅发布到 GitHub，以预发布版提供；普通 AE2 整合包请使用常规版本。源码包供开发者使用。

## English

**Minecraft 1.20.1 / Forge · GregTech Odyssey prerelease · Dev25 support**

This release supports GregTech Odyssey **0.6.0-dev25 (Dev25, shown as 0.6.0.25 in the instance directory)**.
Starting with this release, GTO editions use the supported modpack version instead of the regular ECO `20.x-gto.x` numbering.

Compared with the published release: `20.5.1-gto.1`

### Support and improvements

- Adapt the Dev25 GTO AE2 crafting confirmation entry points while preserving ECO planning, confirmed submission and processing accounting.
- Adapt the GTO crafting CPU status menu's pause reads, pause changes, crafting result synchronization and pending-position queries while preserving the native features.
- Register large workstation upgrade modules according to their corresponding installed addon mods.

### Fixes

- Fix crafting submission injection failing to match Dev25's overloaded confirmation entry points.
- Fix opening the crafting status menu crashing when the ECO CPU wrapper is cast directly to GTO's native CPU type.
- Fix the CPU menu bridge's Mixin priority conflict that crashed the client during startup registration.
- Include the loot fixes prepared for `20.5.2-gto.1`: correct Minecraft 1.20.1 Silk Touch predicates in nine crystal, energized crystal budding block, aluminum ore and tungsten ore loot tables. Energized crystal clusters yield four energized crystals with ordinary mining and the block itself with Silk Touch.

### Installation and verification

- The adapted and inspected instance uses GTO **0.6.0-dev25**, Forge **47.4.20**, GTOCore **26.10.18**, GTO AE2 **15.2610.40** and **Java 21**.
- Install `neoecoae-0.6.0-dev25.jar` on both client and server and remove previous NeoECOAE JARs. The network handshake requires identical ECO versions on both sides.
- All 27 focused GTO regression tests passed without skips after the fix. The full instance passed the previous startup crash point, all four crafting CPU menu bridges were confirmed in the transformed runtime class, and normal operation was confirmed in the Dev25 instance.
- This release makes no new acceptance claims for a standalone dedicated server, all addon combinations or the full legacy test suite.
- Published on GitHub only as a prerelease. Use the regular edition for ordinary AE2 modpacks. The sources archive is for developers.
