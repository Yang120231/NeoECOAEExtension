## 中文

**Minecraft 1.20.1 / Forge · GregTech Odyssey 专用预发布版**

对比版本：`20.5.1-gto.1`

### 修复

- 修复水晶簇、水晶芽、盈能水晶母岩、铝矿和钨矿共 9 张掉落表的精准采集谓词格式，使其符合 Minecraft 1.20.1 的 `minecraft:match_tool` 解析格式。
- 修复盈能水晶簇掉落分支：普通挖掘掉落 4 个盈能水晶，精准采集掉落方块本身。

### 安装与验证范围

- 适配目标保持为 GregTech Odyssey `0.6.0.23`、GTOCore `26.10.9`、GTO GTM `26.10.70`、GTO AE2 `15.2610.31`；目标实例使用 Java 21。
- 客户端和服务端均替换为 `neoecoae-20.5.2-gto.1.jar`，移除旧版 NeoECOAE JAR。网络握手要求两端 ECO 版本完全一致。
- `processResources jar` 构建成功；发布 JAR 内 9 张掉落表资源均已验证通过。
- GTO 兼容性回归测试 20 项全部通过。
- `runData` 仍受仓库已有的可选 ExtendedAE 类缺失阻塞，不影响本次掉落表资源和 JAR 打包验证。
- 本次仅发布到 GitHub，以预发布版提供；普通 AE2 整合包请使用常规版本。源码包供开发者使用。

## English

**Minecraft 1.20.1 / Forge · GregTech Odyssey prerelease**

Compared with: `20.5.1-gto.1`

### Fixes

- Fix the Silk Touch predicate format in the nine crystal cluster, crystal bud, energized crystal budding block, aluminum ore and tungsten ore loot tables so Minecraft 1.20.1 can parse their `minecraft:match_tool` conditions.
- Fix the energized crystal cluster drops: ordinary mining yields four energized crystals, while Silk Touch yields the block itself.

### Installation and verification

- Targets remain GregTech Odyssey `0.6.0.23`, GTOCore `26.10.9`, GTO GTM `26.10.70` and GTO AE2 `15.2610.31`. The target instance uses Java 21.
- Install `neoecoae-20.5.2-gto.1.jar` on both client and server and remove previous NeoECOAE JARs. The network handshake requires identical ECO versions on both sides.
- `processResources jar` completed successfully; all nine loot table resources were verified inside the release JAR.
- All 20 GTO compatibility regression tests passed.
- `runData` remains blocked by the repository's existing optional ExtendedAE missing-class issue; this does not affect the loot resource or JAR packaging verification.
- Published on GitHub only as a prerelease. Use the regular edition for ordinary AE2 modpacks. The sources archive is for developers.
