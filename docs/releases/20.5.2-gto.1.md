## 中文

**Minecraft 1.20.1 / Forge · GregTech Odyssey 专用预发布版**

Neo ECO AE Extension **20.5.2-gto.1**，适配 GregTech Odyssey **0.6.0-dev25（Dev25）**：GTOCore **26.10.18**、GTO GTM **26.10.80**、GTO AE2 **15.2610.40**。目标实例使用 Java 21。

### 支持与改进

- 适配 GTO 原生合成 CPU、样板派发与 Dev25 合成确认入口，保留 ECO 合成规划、加工记账和工作站任务归属。
- 恢复单体集成工作站、大型集成工作站的配方加载及 EMI 分类，支持配方重载和旧配方清理。
- 支持使用 GTO 样板修改器 Pro 修改 ECO 大型集成工作站通信接口中的样板。
- 适配 GTO AE2 的库存、精确数量同步与嵌套网络存储列举接口。
- 支持 GTO 合成 CPU 状态界面的暂停读取、暂停设置、合成结果同步与待处理位置查询。
- 大型工作站升级模块按对应附属 Mod 的实际加载状态注册。

### 修复

- 修复 Dev25 合成确认入口存在重载时无法匹配提交注入点的问题。
- 修复打开合成状态界面时，将 ECO CPU 包装器直接转换为 GTO 原生 CPU 类型导致的崩溃。
- 修复 CPU 界面桥接的 Mixin 优先级冲突，避免客户端在启动注册阶段崩溃。
- 修复水晶簇、水晶芽、盈能水晶母岩、铝矿和钨矿共 9 张掉落表的精准采集谓词格式，使其符合 Minecraft 1.20.1 的 `minecraft:match_tool` 解析格式。盈能水晶簇普通挖掘掉落 4 个盈能水晶，精准采集掉落方块本身。
- 保留此前 AE2 图标默认接口调用兼容修复，以及天空石粉的 `forge:dusts/sky_stone` 标签修复。
- 保留远程机器 UI 同步工厂的专服客户端类加载隔离修复。

### 安装与验证范围

- 客户端和服务端均安装 `neoecoae-20.5.2-gto.1.jar`，移除旧版 NeoECOAE JAR。网络握手要求两端 ECO 版本完全一致。源码包供开发者使用；本次不分发临时终端诊断模组。
- 本版本面向上述 GTO Dev25 依赖组合，实例使用 Forge **47.4.20** 和 Java **21**；普通 AE2 整合包请使用普通版本。
- 修复后的 27 项 GTO 专题回归测试全部通过、无跳过。完整实例启动已通过原崩溃点，运行时合成 CPU 菜单的四处桥接均已确认命中，Dev25 实例已确认修复正常。
- 本次仅发布到 GitHub，以预发布版提供；完整旧测试套件、全部附属组合和独立专服尚未完成验收。

## English

**Minecraft 1.20.1 / Forge · GregTech Odyssey prerelease**

Neo ECO AE Extension **20.5.2-gto.1**, targeting GregTech Odyssey **0.6.0-dev25 (Dev25)** with GTOCore **26.10.18**, GTO GTM **26.10.80** and GTO AE2 **15.2610.40**. The target instance uses Java 21.

### Support and improvements

- Adapt GTO's native crafting CPU, pattern dispatch interfaces and Dev25 crafting confirmation entry points while preserving ECO planning, processing accounting and workstation job ownership.
- Restore recipe loading and EMI categories for both integrated workstations, including recipe reloads and removal of stale recipes.
- Support GTO's Pattern Modifier Pro on the ECO Large Integrated Workstation communication interface.
- Adapt GTO AE2 inventory APIs, exact amount synchronization and nested network storage listing.
- Support the GTO crafting CPU status menu's pause reads, pause changes, crafting result synchronization and pending-position queries.
- Register large workstation upgrade modules according to their corresponding installed addon mods.

### Fixes

- Fix crafting submission injection failing to match Dev25's overloaded confirmation entry points.
- Fix opening the crafting status menu crashing when the ECO CPU wrapper is cast directly to GTO's native CPU type.
- Fix the CPU menu bridge's Mixin priority conflict that crashed the client during startup registration.
- Fix Minecraft 1.20.1 `minecraft:match_tool` Silk Touch predicates in nine crystal, energized crystal budding block, aluminum ore and tungsten ore loot tables. Energized crystal clusters yield four energized crystals with ordinary mining and the block itself with Silk Touch.
- Retain the earlier AE2 icon default-interface compatibility fix and the `forge:dusts/sky_stone` tag fix for sky stone dust.
- Retain the dedicated-server client-class isolation fix for the remote machine UI synchronization factory.

### Installation and verification

- Install `neoecoae-20.5.2-gto.1.jar` on both client and server and remove previous NeoECOAE JARs. The network handshake requires identical ECO versions on both sides. The sources archive is for developers; the temporary terminal diagnostic mod is not distributed.
- This build targets the GTO Dev25 dependency versions listed above, using Forge **47.4.20** and Java **21**. Use the regular edition for ordinary AE2 modpacks.
- All 27 focused GTO regression tests passed without skips after the fix. The full instance passed the previous startup crash point, all four crafting CPU menu bridges were confirmed in the transformed runtime class, and normal operation was confirmed in the Dev25 instance.
- This prerelease is published on GitHub only. The full legacy test suite, all addon combinations and a standalone dedicated server have not completed acceptance testing.
