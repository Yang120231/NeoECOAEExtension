## 中文

**Minecraft 1.20.1 / Forge · GregTech Odyssey 专用预发布版**

Neo ECO AE Extension **20.5.3-gto.1**，延续 GTO Dev25 专版适配。编译依赖固定为 GTO AE2 **15.2610.31**；此前 Dev25 运行适配目标为 GTO AE2 **15.2610.40**。本次未重新进行完整实例验收，目标实例仍使用 Java 21。

### 配方与工作站

- 恢复 ECO 单体集成工作站、大型集成工作站、模块及其 EMI/JEI 分类和多方块预览。
- GTO 材料配方由 ECO 集成工作站处理，沿用规划中的材料与加工时长，按目标整合包的 **1 EU = 8 AE** 换算总耗能；超过 9 种输入的配方放入大型工作站，最多 12 种输入。
- 保留工作站本体及其前置材料的独立制作链，避免必须先拥有工作站才能制作工作站；修复同优先级配方包排序导致 GTO 配方被 GTM 配方覆盖的问题。
- ECO 无限组件与 GTO 无限组件仅通过工作台双向 **1:1** 兑换，取消共享组件标签和额外工作站生产入口。
- 新增 AE2 充能器将四种赛特斯石英母岩转换为对应盈能水晶母岩的配方，支持 GTO 无法召唤闪电时启动水晶生长；破损母岩转换为缺损盈能母岩。

### 修复与性能

- 延迟初始化 EMI 分类，修复 GTO 提前加载 EMI 插件时过早初始化 ECO 注册内容的问题。
- 更早识别循环合成缺少启动物料的死锁，报告阻塞物料，减少无效搜索。
- 改进循环合成种子保留：订单恰好耗尽库存时，尽可能增产并留下可再次启动的物料；无法增产时仍保留原本可完成的订单。
- 优化大数规划、存储数量运算、存储列表缓存和 MEGA 解压输出遍历，保持精确数量与持久化格式。
- 补齐干净检出所需的 GTO 依赖锁文件，使发布构建能够恢复固定依赖。

### 安装与验证

- 客户端和服务端均安装 `neoecoae-20.5.3-gto.1.jar`，移除旧版 NeoECOAE JAR；两端版本必须一致。`-sources.jar` 为开发者源码包。
- 本地安装包、源码包构建及 JAR 检查通过，配方生成一致性检查通过。GTO 专题共 54 项测试，51 项通过、3 项跳过、0 失败；跳过项需要提供目标实例的 AE2/GTOCore JAR。
- 本次未重新启动开发客户端、完整 GTO 实例或独立专服，也未运行完整旧测试套件。本版本仅在 GitHub 以预发布版提供。

## English

**Minecraft 1.20.1 / Forge · GregTech Odyssey prerelease**

Neo ECO AE Extension **20.5.3-gto.1**, continuing the GTO Dev25 adaptation. Compilation is pinned to GTO AE2 **15.2610.31**; the previously documented Dev25 runtime target uses GTO AE2 **15.2610.40**. Full instance acceptance was not repeated for this release. The target instance uses Java 21.

### Recipes and workstations

- Restore ECO's Integrated Workstation, Large Integrated Workstation, modules, EMI/JEI categories and multiblock previews.
- Process GTO material recipes in ECO workstations using the planned materials and durations, converting total energy at the target pack's **1 EU = 8 AE** ratio. Recipes with more than nine inputs use the large workstation, with at most twelve inputs.
- Preserve standalone recipes for the workstation and its prerequisites so the progression chain can start. Fix recipe pack ordering that allowed GTM recipes to override GTO replacements.
- Exchange ECO and GTO infinite components **1:1** in either direction on the crafting table, without shared component tags or additional workstation production routes.
- Add AE2 charger recipes converting four Certus Quartz budding variants into energized crystal budding blocks, providing a way to start crystal growth without summoning lightning in GTO. Damaged budding quartz produces chipped energized budding.

### Fixes and performance

- Defer EMI category initialization to prevent GTO's early plugin loading from initializing ECO registrations prematurely.
- Detect crafting cycles blocked by missing starting materials earlier, report blocked materials and reduce futile searches.
- Improve renewable seed retention when an order would consume all existing stock. Keep the original successful plan when additional production is unavailable.
- Optimize exact amount arithmetic, storage listing caches and MEGA decompression traversal while preserving exact quantities and persistence formats.
- Include the pinned GTO dependency lock required to restore build dependencies in a clean checkout.

### Installation and verification

- Install `neoecoae-20.5.3-gto.1.jar` on both client and server, removing older NeoECOAE JARs. Both sides require the same version. The sources archive is for developers.
- Local mod and sources builds, artifact checks and generated recipe consistency checks passed. Of 54 focused GTO tests, 51 passed, three were skipped and none failed. Skipped tests require the target instance's AE2/GTOCore JARs.
- The development client, full GTO instance, standalone dedicated server and full legacy test suite were not rerun for this release. Published on GitHub only as a prerelease.
