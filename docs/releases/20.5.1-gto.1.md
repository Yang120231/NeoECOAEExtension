## 中文

**Minecraft 1.20.1 / Forge · GregTech Odyssey 专用预发布版**

对比版本：`20.5.0-gto.1`

### 修复

- 修复远程机器界面的同步工厂在专用服务器初始化时加载客户端类，导致服务器启动崩溃的问题。保留两端共同需要的界面工厂注册，客户端界面读取按物理运行端隔离。

### 安装与验证范围

- 适配目标保持为 GregTech Odyssey `0.6.0.23`、GTOCore `26.10.9`、GTO GTM `26.10.70`、GTO AE2 `15.2610.31`；目标实例使用 Java 21。
- 客户端和服务端均替换为 `neoecoae-20.5.1-gto.1.jar`，移除旧版 NeoECOAE JAR。网络握手要求两端 ECO 版本完全一致。
- 保留上一版的 GTO 原生 CPU、样板派发、配方加载和 EMI 适配。本次版本号不代表已合入常规版 20.5.1 的全部非 GTO 改动。
- 20 项回归测试全部通过，覆盖 GTO 专题、远程机器 UI 专服类加载隔离和网络版本匹配；发布 JAR 与配方生成检查通过。完整旧测试套件、独立专服实际启动及本次真实联网界面交互尚未完成验收。
- 本次仅发布到 GitHub，以预发布版提供；普通 AE2 整合包请使用常规版本。源码包供开发者使用。

## English

**Minecraft 1.20.1 / Forge · GregTech Odyssey prerelease**

Compared with: `20.5.0-gto.1`

### Fixes

- Fix dedicated server initialization crashing when the remote machine UI synchronization factory loads client-only classes. Keep the shared factory registered on both sides and isolate client UI reads by physical side.

### Installation and verification

- Targets remain GregTech Odyssey `0.6.0.23`, GTOCore `26.10.9`, GTO GTM `26.10.70` and GTO AE2 `15.2610.31`. The target instance uses Java 21.
- Install `neoecoae-20.5.1-gto.1.jar` on both client and server and remove previous NeoECOAE JARs. The network handshake requires identical ECO versions on both sides.
- Retain the previous GTO native CPU, pattern dispatch, recipe loading and EMI adaptations. This version number does not imply that every non-GTO change from the regular 20.5.1 release has been merged.
- All 20 regression tests passed, covering GTO adaptations, dedicated-server class-loading isolation for the remote machine UI and network version matching. Release JAR and recipe generation checks passed. The full legacy test suite, an actual standalone dedicated server startup and live multiplayer UI interactions have not completed acceptance testing for this release.
- Published on GitHub only as a prerelease. Use the regular edition for ordinary AE2 modpacks. The sources archive is for developers.
