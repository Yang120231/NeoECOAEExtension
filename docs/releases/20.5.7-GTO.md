## 中文

**Minecraft 1.20.1 / Forge · GregTech Odyssey 专用正式版**

Neo ECO AE Extension **20.5.7-GTO**，编译依赖为 GTOCore **26.10.26**、GTO AE2 **15.2610.47**，游戏运行使用 **Java 21**。以下更新相对于 `20.5.6-GTO`。

- 增加轻量合成模式，按材料优先样板进行单次遍历，减少替代路线搜索。
- 轻量规划保留循环和加工输入的忽略 NBT 规则，按实际消耗记录材料变体；循环仅使用剩余库存闭合，不自动切换到完整规划。
- 为 GTO 二合一终端增加样板上传按钮，统一复用 AE2 与 GTO 终端的上传及空白样板返还逻辑；上传按钮统一放入左侧工具栏。
- 修复专服加载共享 UI 纹理时解析客户端类的问题，隔离客户端绘制、槽位提示、UI 桥接和资源访问。
- 优化合成产物回流的 CPU 查找、归属校验和回退处理。
- 修复机壳碰撞体积，将机壳形状调整为完整方块。
- 补充与主线的功能差异及专服 UI 修复说明。

本次验证包括本地构建、安装包和源码包检查，以及 Forge 分端类加载检查；未进行真实客户端、专服或游戏内交互验收。

## English

**Minecraft 1.20.1 / Forge · GregTech Odyssey stable release**

Neo ECO AE Extension **20.5.7-GTO**, compiled against GTOCore **26.10.26** and GTO AE2 **15.2610.47**. The game requires **Java 21**. Changes below are relative to `20.5.6-GTO`.

- Add lite crafting mode with one traversal using the preferred producer for each material, reducing alternative-route searches.
- Preserve cycles and explicit NBT-insensitive processing-input rules within lite planning, recording the actual material variants consumed. Cycles close only against remaining stock without switching to full planning.
- Add pattern upload to the GTO two-in-one terminal, sharing upload and blank-pattern settlement with the AE2 terminal. Place upload buttons in the left toolbar.
- Fix dedicated-server loading of shared UI textures by isolating client drawing, slot tooltips, UI bridging and resource access.
- Improve crafting-output return routing, CPU lookup, ownership checks and fallback behavior.
- Fix casing collision shapes to occupy a full block.
- Document differences from the mainline edition and the dedicated-server UI fix.

Validation covers the local build, mod and sources archives, and Forge side-specific class loading. Real client, dedicated-server and in-game interactions have not been verified for this release.
