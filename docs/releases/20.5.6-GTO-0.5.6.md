## 中文

**Minecraft 1.20.1 / Forge · GTO 0.5.6-beta 专用适配版**

版本：**20.5.6-GTO-0.5.6**。游戏运行需要 **Java 21**。

本包面向 GTOCore **0.5.6-beta**、GTOLib **26.7.4**、GTCEu **26.7.3**、GTO AE2 **15.267.4**、EMI **1.1.24**。请勿作为新版 GTO 的通用更新包使用。

- 修正依赖版本声明；复用 GTCEu 内置的 DataSyncLib，不再要求额外安装独立 DataSyncLib。
- 适配旧版 AE2 的数量表、合成计划、存储变更接口、图标及终端刷新路径，保留大数量处理能力。
- 修复样板供应器 Mixin 定位错误导致的启动崩溃。
- 将工作站配方插件接入 GTO 的公开 EMI 注册事件，补回大集成接口的配方查询入口，并使用当前世界注册表读取配方。

**验证范围：** 本地构建与成品检查通过；样板供应器修复后的版本已实际启动进入存档。最后一项 EMI 配方修复已通过编译和归档检查，尚未完成游戏内复测。未进行完整合成、存储及专用服务器功能验收。

安装时替换原有 NeoECOAE JAR，避免同时保留多个版本。`-sources.jar` 为源码附件，不要放入 mods 目录。

## English

**Minecraft 1.20.1 / Forge · Compatibility build for GTO 0.5.6-beta**

Version: **20.5.6-GTO-0.5.6**. The game requires **Java 21**.

Targets GTOCore **0.5.6-beta**, GTOLib **26.7.4**, GTCEu **26.7.3**, GTO AE2 **15.267.4**, and EMI **1.1.24**. This is not a general update for newer GTO packs.

- Correct dependency ranges and use DataSyncLib embedded in GTCEu instead of requiring the standalone mod.
- Adapt amount maps, crafting plans, storage change tracking, icons, and terminal refresh paths to the older AE2 fork while retaining large-quantity handling.
- Fix the pattern-provider Mixin target that prevented startup.
- Register workstation recipes through GTO's public EMI plugin event, restore recipe lookup from the large workstation interface, and use the current world's registries.

**Validation:** Local builds and archive checks passed. The pattern-provider fix was verified by launching and entering a world. The final EMI recipe fix passed compilation and archive checks but has not been retested in game. Full crafting, storage, and dedicated-server acceptance testing remains outstanding.

Replace the existing NeoECOAE JAR rather than installing both versions. The `-sources.jar` attachment is source code and should not be placed in the mods directory.
